# 情绪日记 · 自我关怀

一个本地优先、零后端的情绪日记与自我关怀 Web 应用。数据只保存在浏览器本地（`localStorage`），隐私安全、开箱即用。

## 功能

- **记录情绪变化** —— 8 种情绪（带 emoji）＋强度（1–10）＋触发因素标签＋备注
- **情绪可视化** —— 强度随时间折线图、情绪分布条形图
- **触发因素分析** —— 自动聚合各触发标签的出现次数 / 平均强度 / 负面次数，并给出高频负面触发洞察
- **自助调节推荐** —— 依据最近一条心情，从冥想 / 音乐 / 运动内容库中推荐 Top 3，支持「有帮助 / 没帮助」反馈闭环

## 技术栈

Vite + React 18 + TypeScript + Tailwind CSS + Recharts + Zustand

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 <http://localhost:5173/>

> 注意：请通过上面的开发服务器地址访问，不要直接双击 `index.html`（`file://` 协议下模块脚本无法加载）。

## 构建

```bash
npm run build
npm run preview
```

## 隐私说明

所有情绪记录仅存储在你自己的浏览器本地，不会上传到任何服务器。
